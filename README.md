# Plataforma de Adopción de Animales

Trabajo de Fin de Grado (Grado Superior en Desarrollo de Aplicaciones Multiplataforma).

## Descripción
Plataforma para conectar adoptantes con protectoras de animales, con una app 
multiplataforma para los usuarios y un sistema de gestión (CRM) en Salesforce 
para que las protectoras controlen todo el proceso de adopción y seguimiento 
sanitario de forma profesional.

## Tecnologías
- **Frontend:** Vue.js + Quasar
- **Backend:** Java 17 (Spring Boot) — en desarrollo
- **Base de datos:** PostgreSQL
- **Gestión (CRM):** Salesforce Service Cloud — en desarrollo
- **Comunicación:** API REST
